# Противники ладдера

Положи сюда файлы противников в том же формате UTF-8, что и файлы из `Characters/`.
Персонажей в этой папке генератор не создаёт.
Сейчас здесь лежат три учебные пустышки с возрастающей сложностью; их можно заменить своими файлами.

Добавь в каждый файл отдельную строку с положительным целым индексом сложности:

```text
ladder_index: 1
```

Забег идёт по возрастанию `ladder_index`: меньший индекс означает более ранний бой.
Если у нескольких противников индекс совпадает, они идут по имени файла.
Например, противника с `ladder_index: 1` нужно поместить перед противником с
`ladder_index: 2`.

Файлы противников и выбранного героя во время ладдера не изменяются.

## Портреты злодеев

Портрет задаётся в файле злодея через поле `image`. Путь указывается относительно
корня проекта; изображения хранятся в `CardTemplates/villains/` — рядом с
категориями `races`, `characters` и `weapons`:

```text
image: CardTemplates/villains/necromancer.png
```

Положи файл по адресу `CardTemplates/villains/necromancer.png`. Используй PNG с
вертикальным соотношением сторон примерно 2:3: игра уменьшит изображение,
сохранив пропорции, и покажет его в портрете бойца. Если путь пустой или
изображение не найдено, вместо него будет показано имя злодея. Автоматическая
сборка портрета из расы, фигуры и оружия для противников ладдера отключена.
