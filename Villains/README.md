# Противники ладдера

Положи сюда файлы противников в том же формате UTF-8, что и файлы из `Characters/`.
Персонажей в этой папке генератор не создаёт.
Сейчас здесь лежат три учебные пустышки с возрастающей сложностью; их можно заменить своими файлами.

Добавь в каждый файл отдельную строку с положительным целым индексом сложности:

```text
ladder_index: 1
```

Забег идёт по возрастанию `ladder_index`: меньший индекс означает более ранний бой.
Если у нескольких противников индекс совпадает, они идут по имени файла.
Например, противника с `ladder_index: 1` нужно поместить перед противником с
`ladder_index: 2`.

Файлы противников и выбранного героя во время ладдера не изменяются.
