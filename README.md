# ⚔️ Неудачный забег

Игра на Python и Tkinter: создавай случайных героев, смотри их карточки, устраивай сражения и проводи турниры.

## Возможности

- **Генератор героев.** Имя проверяется по допустимым латинским и кириллическим буквам, пробелам и дефисам. Характеристики выбираются по весам из `data.py`; доступный пропуск сразу завершает текущую прокрутку. Можно включить быстрое вращение.
- **Лорные страницы.** Вступительная хроника находится в `lore.md`, а текст после победы над всеми противниками ладдера — в `lore_ending.md`. Обе страницы поддерживают Markdown, автопрокрутку, ручную прокрутку и паузу. Вступление можно открыть из главного меню; после полного прохождения ладдера игра показывает поздравление и открывает финальную хронику.
- **Коллекция.** Поиск по персонажам, сортировка по дате создания, имени, очкам или статусу, фильтр по расе и просмотр подробностей. Карточка собирается из фона расы, фигуры нужного роста и оружия. Силу, скорость, интеллект, боевые навыки, владение оружием и мощь способности можно прокачивать за очки: первый уровень стоит 5 очков, каждый следующий вдвое дороже (10, 20, 40, 80). Мёртвых героев прокачивать нельзя.
- **Сражения.** Выбери двух героев и наблюдай сравнение атрибутов на колесе. Бросок удачи каждого бойца (1–20) раскладывается по раундам, так что счёт раунда — это характеристика плюс доля удачи, а строка «Итог» показывает сумму всех раундов. Проигравший раунд боец вспыхивает красным, как от удара. История раундов прокручивается к новой записи автоматически; по итогам показываются победитель и карточки участников.
- **Забег в ладдер.** Выбери живого героя из коллекции и пройди злодеев из `Villains/` по возрастанию `ladder_index`. За победой над последним противником следуют поздравление и финальная лорная страница. Если герой проигрывает бой, у него сохраняется `live_status: False`, а очки обнуляются; злодеи не умирают и их файлы не меняются. Погибшие герои отмечаются в коллекции красным и исключаются из ладдера, обычных сражений и турниров. Счётчик и JSON-история обновляются только после победы над всеми злодеями или поражения. В историю записываются герой, порядок противников и результат. Очки участников не меняются.
- **Турниры.** Собери ростер минимум из 20 героев или автоматически добавь первые 20 в списке. Турнир включает групповой этап и плей-офф; доступны таблицы групп, сетка, отчёт и чемпион.
- **Интерактивная сетка.** Перетаскивание мышью, кнопки масштаба, вписывание в окно и перемещение стрелками клавиатуры. Колесо мыши и тачпад двигают сетку (с `Shift` — по горизонтали), `Ctrl` + колесо или тачпад меняет масштаб, клавиша `0` вписывает сетку.
- **Прокрутка колесом и тачпадом** работает на Windows, macOS и Linux, в том числе с тачпадами MacBook на Tk 8.6 и Tk 9 (Python из Homebrew). В маленьком окне страницы арены и турнира прокручиваются целиком.
- **Опции окна.** Светлая или тёмная тема, полноэкранный режим и выбор разрешения. `Esc` выходит из полноэкранного режима.
- **Музыка и эффекты.** Пять фоновых лупов сопровождают лор, главное меню, коллекцию, турнир и бой. Звуковые эффекты отмечают нажатия, ошибки, начало режимов, исходы раундов и боёв, создание героя, улучшение характеристик и завершение турнира или ладдера. Звук можно выключить или изменить общую громкость в настройках. Там же выбирается устройство вывода (колонки, наушники, монитор), есть кнопки «Обновить» и «Проверить» и строка состояния. Если выбранное устройство отключить, звук перейдёт на системное и вернётся, когда устройство снова подключат; ошибки звука не роняют игру, а показываются в настройках и пишутся в журнал. Сейчас используются временные синтезированные WAV-файлы, которые можно заменить своими, сохранив имена и пути.

## Запуск

Нужны Python, Tkinter и pygame-ce. Зависимости устанавливаются командой:

```bash
python -m pip install -r requirements.txt
```

Из папки проекта запусти графическое приложение:

```bash
python gui.py
```

Либо запусти консольную генерацию персонажа:

```bash
python main.py
```

## Данные и настройки

- Созданные персонажи сохраняются в `Characters/<имя>.txt` в UTF-8. Дата создания хранится в поле `created_at` (ISO 8601) и задаёт порядок героев на арене, в турнире и в коллекции; герои без этого поля показываются в конце списка.
- Варианты характеристик и их веса находятся в `data.py`. Вес в списке `*_weights` соответствует элементу на той же позиции в списке вариантов. Важны соотношения весов, сумма необязательно равна 100.
- `settings.json` задаёт настройки темы, окна, включения звука, громкости и устройства вывода (`audio_device`; `null` — системное по умолчанию). Приложение обновляет его при изменении параметров. Файл личный и в git не хранится; если его нет, игра стартует с настройками по умолчанию: тёмная тема, окно, звук включён, громкость 70%, системное устройство вывода.
- `unlucky_run.log` — журнал последнего запуска: какое аудиоустройство открыто, его формат, список доступных устройств, ошибки звука и необработанные ошибки интерфейса. Файл перезаписывается при каждом запуске; если на каком-то компьютере нет звука, начните с него.
- Если заменяешь графику карточек, сохраняй имена и расположение PNG-файлов в `CardTemplates/`. Рекомендации для шаблонов находятся в [`CardTemplates/README.md`](CardTemplates/README.md).
- Звуковые файлы размещаются в `music/`; полный список дорожек и эффектов описан в [`music/README.md`](music/README.md). Фоновые дорожки лежат в `music/background/`, короткие эффекты — в `music/effects/`.

## Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `gui.py` | Главное окно, экраны приложения, генератор, коллекция, арена, турнир и опции |
| `audio.py` | Загрузка фоновых дорожек и эффектов, громкость, выключатель звука, выбор устройства вывода и восстановление после ошибок |
| `lore.md` | Markdown-текст вступительной хроники |
| `lore_ending.md` | Markdown-текст финальной хроники после победы в ладдере |
| `main.py` | Модель персонажа, генерация и сохранение |
| `data.py` | Варианты характеристик и веса случайного выбора |
| `Fight.py` | Подсчёт характеристик и логика сражений |
| `Tournament.py` | Групповой этап, таблицы и плей-офф |
| `Characters/` | Текстовые файлы созданных персонажей |
| `Villains/` | Файлы противников для ладдера; каждому нужен положительный `ladder_index` |
| `LadderRuns/` | JSON-файл каждого запуска ладдера с героем, прогрессом и результатом |
| `CardTemplates/` | Фоны рас, изображения персонажей, оружия и злодеев |
| `music/` | Фоновые дорожки и звуковые эффекты |
| `fonts/` | Шрифты оформления Ruslan Display и Kurale (лицензия SIL OFL 1.1); игра подключает их сама, устанавливать не нужно |
| `settings.json` | Локальные настройки приложения, создаётся при изменении опций |
| `unlucky_run.log` | Журнал последнего запуска, создаётся при старте `gui.py` |

- Tkinter / ttk
