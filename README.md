# ⚔️ Неудачный забег

Небольшая настольная игра-генератор на Python и Tkinter. Создавай случайных героев, наблюдай за бросками на колесе удачи, устраивай дуэли и собирай турнирный ростер.

<div align="center">

**Создай героя · Проверь его в бою · Победи лошков**

</div>

## ✨ Возможности

- **Генерация персонажей** — происхождение, раса и подраса, рост, сила, скорость, интеллект, боевые навыки, оружие, способность, влияние хаоса и титул.
- **Колесо атрибутов** — значение выбирается с учётом весов; размер секторов соответствует шансам выпадения. Результаты появляются по одному, по мере прокрутки.
- **Коллекция персонажей** — просмотр сохранённых героев из папки `Characters`.
- **Сражения** — сравнение характеристик двух выбранных героев с прокруткой колеса для каждого атрибута и итоговым отчётом.
- **Турниры** — ростер минимум из 20 героев, групповой этап и плей-офф с отображением итоговой сетки и чемпиона.
- **Тёмная тема** — включается в разделе «Опции».

## 🚀 Запуск

Нужен Python с установленным Tkinter. Дополнительные библиотеки проекту не требуются.

Из корневой папки проекта запусти графический интерфейс:

```bash
python gui.py
```

Можно запустить генератор из консоли:

```bash
python main.py
```

## 🎲 Настройка шансов

Списки вариантов и веса находятся в `data.py`. Вес каждого значения расположен на той же позиции в соответствующем списке. Чем больше вес, тем выше вероятность выбора.

Например:

```python
size_sum = ['Маленький', 'Средний', 'Крупный', 'Гигантский']
size_weights = [2, 6, 3, 1]
```

«Средний» будет выпадать чаще остальных. Сумма весов не обязана быть равна 100: для выбора важны их соотношения.

## 📁 Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `gui.py` | Окна приложения, меню, колесо генерации, сражения и настройки темы |
| `main.py` | Класс персонажа, генерация и сохранение героя |
| `data.py` | Варианты атрибутов и веса для случайного выбора |
| `Fight.py` | Сравнение персонажей и результаты боя |
| `Tournament.py` | Групповой этап, плей-офф и отчёт о турнире |
| `Characters/` | Сохранённые персонажи в текстовом формате |

## 💾 Сохранения

Созданные герои записываются в `Characters/<имя>.txt`.
